# GlyphMatics ARCAGI3 Top-5 Public Notebook Known Prior v0.9.3

Branch:

dev/v0.9-horizontal-vertical-priors

## Purpose

Combine the five highest-scoring locally available public/owned ARCAGI3 notebooks into one known prior.

## Ranking Rule

1. Highest detected notebook score.
2. ARCAGI3 relevance if no score is detected.
3. Code size.
4. Modified time.

## Extracted Structures

- notebook code cells
- imports
- functions
- classes
- call patterns
- solver layers
- repeated code lines
- code SHA256 hashes
- score metadata when detectable

## Solver Layer Buckets

- object detection
- grid transform
- color reasoning
- pattern completion
- search/planning
- heuristics
- program synthesis
- ensemble/fallback
- submission I/O
- neuro-symbolic logic

## Boundary

Public/owned local notebooks only.

This prior stores symbolic and structural notebook patterns. It does not claim arbitrary byte compression and does not include private notebooks unless the user explicitly placed them in the scanned roots.
