# GlyphMatics Prior Family Lock

The prior family builds legal/shared symbolic runtime knowledge for GlyphMatics compression.

## Priors

- arcagi3_prior
- llama_cpp_prior
- gguf_prior
- transformer_prior
- notebook_solver_prior
- kaggle_submission_prior
- agent_runtime_prior
- visual_artifact_prior

## Rule

Compression is achieved by shared prior + program induction + symbolic dictionary.

No private data.
No stolen repositories.
No hidden payloads.
No base64 byte wrapping.
No byte-to-Braille.
No byte-to-Hanzi.

## Boundary

A tiny sigil can represent a large artifact only when the runtime has the legal shared prior needed to regenerate or behaviorally reconstruct it.
