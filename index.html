Format Lock

Raw visual files use a binary PGM/P5 image. The pixel raster begins with:

magic[8] = GMVIL02\0 header_len[4] = unsigned big-endian payload_len[8] = unsigned big-endian sha256[32] = SHA-256 of payload bytes header_json[header_len] payload[payload_len] zero padding to width × height
Security rule: G6 Signal is not G15 Key. Observation is not authorization. No G14 Lock without verification.
